# Clashdle

[Play Clashdle](https://clashdle.app/)

Clashdle is a Clash Royale stats guessing game where players identify cards,
evolutions, heroes, abilities, and spawned entities using real in-game stats.

The daily game gives feedback across clues like elixir cost, entity type, card
type, rarity, target, hitpoints, damage, damage per second, and special damage.
